# 공용 세션 제목

Claude와 Codex가 같은 스킬과 스크립트를 사용한다. 성공 기준은 두 대화 이름의 저장이며, Orca 탭 제목은 변경하거나 저장을 확인하지 않는다. `pair`로 시작한 현재 탭의 Claude·Codex 한 쌍을 대상으로 한다.

- Linear 이슈 작업에 실제로 착수하거나 대상 이슈가 바뀌면, Linear에서 확인한 `<실제 이슈 번호> <Linear 원문 제목>`을 사용한다. 번호나 제목을 추측하지 않는다.
- 이슈 없는 업무는 대상과 목표를 담은 짧은 한국어 제목을 사용한다. 업무 주제가 크게 바뀔 때만 갱신한다.
- 사용자가 직접 지정한 제목은 유지한다. 업무가 없거나 스킬 로딩·단순 조회 중이면 바꾸지 않는다. PM·대기 같은 역할·상태는 제목으로 쓰지 않는다.

## 실행

대화가 실행 중인 머신의 연결된 **Codex 터미널**에서 이 스킬의 `scripts/set_title.py`를 실행한다. Claude가 요청받으면 짝 Codex에게 실행을 맡긴다. Claude가 자기 턴에서 `/rename`을 보내면 명령이 대기열에 남을 수 있으므로, 스크립트는 Claude 쪽 실행을 변경 전에 거절한다. 짝 Claude가 입력 대기 상태일 때 실행한다. Claude가 작업 중이면 Codex에서 보내도 `/rename`이 지연될 수 있다. 설치 경로가 다르면 읽은 `SKILL.md` 기준으로 경로를 찾는다.

```sh
python3 /path/to/session-title/scripts/set_title.py 'FDE-123 Linear 원문 제목'
```

스크립트는 현재 환경과 부모 프로세스, Orca의 연결 기록을 대조한다. 환경변수가 없어도 연결이 확인되면 진행하고, 후보가 여럿이거나 연결을 확인하지 못하면 중단한다. 활성 탭·최신 대화·같은 폴더라는 이유만으로 대상을 고르지 않는다. 로컬 경로를 원격 머신에 그대로 넘기지 않는다.

변경 전 이름을 출력한 뒤 Claude `/rename`의 JSONL 저장값, Codex `thread/name/set` 후 `thread/read`로 두 이름의 저장을 확인한다. 일부만 성공할 수 있으므로 두 결과를 구분한다. 실패하면 출력된 이전 이름과 변경된 항목을 알리고 본 업무를 계속한다. 명령 접수만으로 성공이라 하지 않으며, 저장이 확인되지 않은 `/rename`을 무작정 다시 보내지 않는다.


검증 범위: 자동 테스트는 가짜 Orca 연결과 app-server 응답을 사용한다. 실제 실행 중인 Codex TUI가 변경한 이름을 다시 덮어쓰는지는 별도 실사용 검증이 필요하다.
